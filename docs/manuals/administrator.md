# 管理员手册

## 部署与首次初始化

AutoForge 只接受 `--data-dir` 启动参数。首次启动会创建权限为 `0600` 的
`config/platform.json` 与一次性 `config/initial-admin-token`；应用配置不从环境变量读取。
访问 `/setup` 选择 Lite 或填写 Full 内部基础设施地址，保存后重启，再用一次性令牌创建首位
系统管理员。Lite 只使用 SQLite、本地对象目录、SQLite 队列和进程内工作器；Full 使用
PostgreSQL、JetStream、MinIO 与 Redis，但领域/API/UI 语义相同。
Full 模式可在 `config/platform.json` 的 `full.databasePoolMax`（默认 10，范围 1–100）
调整 Web 主请求池、Web 调度线程池的总预算以及每个独立 worker 的连接池上限；高并发完成
上报场景可按负载上调。容量规划按每个 Web 副本最多两份该预算、每个 worker 一份该预算计算，
并为迁移与运维连接留出余量，合计不得超过 PostgreSQL `max_connections`；修改后重启生效。

## 身份、LDAP 与权限

在“访问管理”和“项目管理”中创建本地用户、项目、成员和自定义角色。转移项目负责人、禁用用户、
撤销会话或修改高风险角色前，页面会显示影响范围并要求确认。服务账号与 API 令牌独立于用户
会话和 Runner 身份；令牌只在签发时显示一次，数据库只保存摘要、作用域和过期时间。

创建本地用户时，用户名须为 3–64 位，以字母或数字开头，仅允许字母、数字、点、下划线和
短横线；中文姓名可填写在显示名称中（1–120 个字符）。邮箱可留空，填写时须为有效邮箱地址，
不超过 320 个字符。初始密码须为 12–128 位，同时包含字母、数字和特殊字符。
表单会在创建弹框内列出不符合要求的字段；用户名重复、服务繁忙和网络失败也在弹框内反馈，
保留填写内容供修正重试。创建成功后关闭弹框并显示成功通知，用户首次登录仍须修改初始密码。

在“用户管理”列表中点击目标用户旁的“分配角色”，即可直接分配系统角色或指定项目的角色，
无需切换到角色权限页。弹框会固定显示选中的用户；仅有用户管理权限不能分配角色，系统角色
要求 `role.manage`，项目角色要求对应项目的 `project.manage`，并须有 `role.read` 查看角色。
项目列表只显示有管理权限且未归档的项目，停用角色不可分配。失败在弹框内提示并保留选择；
成功后更新列表中的角色绑定并显示成功通知，同时撤销目标用户的旧会话，需重新登录。

LDAP 在“访问管理 → LDAP 认证”中配置，未启用时收起连接表单。字段与 DDT Insight 一致：服务器、服务 Bind、用户 Base/Filter、
显示名/邮箱属性、Group 属性或 Group Search、统一默认角色、TLS 证书校验和连接超时；bind 密码
加密且不回显。连接测试会区分 DNS、TLS、bind、过滤器、权限和超时。TLS 服务器证书校验默认开启；
隔离的旧目录确实无法提供可信证书时，管理员可以显式关闭，但页面会持续提示中间人攻击风险，且该
设置会写入配置变更审计。目录失联时已有会话按期限继续，本地紧急管理员仍可登录；目录用户的新 LDAP 登录失败，
不会静默回退为同名本地账号。登录页不再要求用户选择账号来源：已有本地账号固定使用本地密码，
已有 LDAP 账号固定使用目录认证，未知用户名在 LDAP 启用时尝试目录即时建号。同名本地账号始终
优先，LDAP 密码不能接管本地身份。LDAP 登录只使用用户过滤器、命中的 DN 和登录框用户名。Group
只写入用户资料供查看，不映射角色或权限；平台不执行手动或计划全量目录同步。

## 凭据、Runner 与终端

产品级执行环境和执行密文已经退役，不存在向用例进程领取或注入受管密文的入口。平台主密钥仍
用于 LDAP bind 密码、Runner 安装连接档案、lease/API 等平台凭据；敏感值不会出现在页面、导出、
审计详情、日志或 spool 中。

在“执行机”填写目标 IP/主机名、SSH 用户和密码，先核对主机指纹，再安装内置 Agent。平台只
支持 Ubuntu/openSUSE；脚本不会执行 `apt`、`apt-get`、`zypper` 或联网下载。成功连接后 SSH
档案由平台主密钥加密保存，可供批量更新复用，API 和浏览器不回传密码。Runner 支持排空、禁用、
凭据轮换/撤销和注销。直连终端默认关闭，需独立权限、短时票据和 Web 副本亲和；断开会清理远端
进程组。

## 保留、诊断与指标

“平台设置 → 数据保留”分别配置执行、日志、产物、来源、分析、审计、会话和队列保留期。先保存策略，
再查看记录数/字节影响预览。修改保留天数会使旧预览失效；执行清理时，服务端校验策略修订号并
使用预览截止时间。删除的业务记录不可恢复，对象删除重试不等于回收站。清理使用持久 lease、重试与死信；对象删除失败不会伪装成功。
诊断包只包含版本、脱敏配置摘要、依赖健康和有界近期错误。指标导出默认关闭，开启后
`/api/v1/metrics` 仍要求 `settings.read` 身份。

## 备份与恢复

Lite 与 Full 的一致备份、恢复、升级前检查和恢复后凭据轮换见
[备份恢复](../operations/backup-recovery.md)。不要执行 `docker compose down --volumes`。
恢复后必须轮换平台主密钥保护边界内的访问凭据、数据库/对象存储密码、LDAP bind 密码和所有
Runner/API 身份，并检查审计记录、对象摘要和 readiness。

故障处置与容量阈值见[容量与故障手册](../operations/capacity-incidents.md)。

## 管理页操作与浏览

- 服务账号、自定义角色和令牌使用同一权限选择器：可按名称或说明搜索，支持全选、取消全选、分组半选与已选数量。搜索后的批选只作用于当前结果；隐藏的已选权限仍保留。服务账号按项目分别配置授权，切换项目不会丢失草稿，允许只拥有项目权限。
- 服务账号每页最多 50 条，点击搜索提交名称/用途和状态筛选；编辑与签发令牌在弹窗内完成。令牌独立显示过期、撤销和账号禁用状态，复制结果通过右上角通知反馈，一次性明文不会因复制失败而重新签发。
- 添加项目成员时先查询候选用户，可一次选择最多 50 人。候选查询与主列表筛选、分页相互独立；转移负责人只列出当前项目成员，密码重置只列本地账号。
- 从用户列表打开角色面板，可查看已有系统/项目角色、撤销可管理范围的绑定，并多选新角色。一次最多提交 50 个绑定。提交前验证整个选择；存储故障时明确说明已完成数量，重试不会重复增加相同绑定。角色变更仍撤销目标用户的旧会话。
- 当前会话有明确标记，终止会话与禁用用户需确认影响；“退出其他会话”保留当前登录。LDAP 关闭时隐藏长表单，重新启用仍保留当前页面草稿。
- 平台配置提供分区导航与圆角固定保存区，未保存时通过页面链接离开或刷新会提示。管理弹窗修改后点击关闭、遮罩或 Escape 会先确认放弃；密码、凭据不写入浏览器持久缓存。
- 执行机组创建和编辑都使用弹窗，成员支持本地搜索与批选，每组仍最多 64 台。版本运行资源按“上传本地压缩包”和“登记内网资源链接”展开，不改变上传、摘要校验与共享继承语义。
- Webhook 提供本地模板样例预览，预览不会发送请求；实际测试发送仍需显式操作。投递历史每页 30 条，支持端点和状态筛选；文件来源与纳管文件每页 50 条，分别支持名称和对象键前缀筛选。列表采用有界游标，不为展示总页数实时统计全库。
- Full 平台节点显示当前节点、地址配置状态；保存地址后可以显式检查连通性。检查使用已保存地址和签名节点协议，验证共享密钥及目标节点 ID，十秒超时且同一节点十秒内限一次。结果仅表示检查时刻，不等同于持续在线监控。旧节点需升级后才能响应新增的 ping 操作，既有日志操作保持兼容。
- 存储空间继续使用后台快照和按需展开的目录；统计口径收进说明，系统诊断保留原始错误并给出中文处理方向。
- 存储清单的旧快照从被替换时起至少保留十分钟，供已开始的分页读取完成。浏览器遇到快照过期会自动从首页重新读取，最多重试两次；Full 模式仍固定原快照所属节点，不混合各节点文件。持续失败时明确提示快照过期并保留“重新扫描”入口，真正的节点连接失败单独提示。恢复读取不会强制触发额外文件扫描。
