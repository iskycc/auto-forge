# Ant Design 界面复查

## 复查范围

本轮按路由、子页、弹窗与共享组件检查，而不是仅检查是否安装了 `antd`。前一轮迁移已完成主题、表单基础控件和离线打包，但仍存在原生折叠面板、自绘弹窗、表格与标签页等遗漏，不能据此前的页面截图判定所有组件已经迁移。

本轮不修改数据库、调度、Runner 协议或业务接口。Lite/Full 共用同一套前端；目录展开加载、服务端分页、后台快照、浏览器缓存及表单修订校验继续保留。

通用控件位于 `apps/web/src/components/ui`，业务模块不再直接声明原生按钮、下拉、文本域、折叠面板、进度条或自绘 dialog/tab/table。`ui-usage.test.ts` 对这些边界和样式占位组件进行检查，避免只替换外观却保留另一套控件实现。

语义容器、正文、业务 SVG 图表、日志虚拟列表和 xterm 终端不是替代 Ant Design 的第二套组件库。表单提交桥接中的隐藏原生字段、文件字段，以及 Table 的自定义行/单元格也保留原生 DOM，以维持浏览器表单和表格语义。颜色与空间参数使用统一主题 token；没有恢复 `globals.css`、远程字体或 CDN。

## 回归中处理的问题

- 服务端页面使用复合组件标题标记时，跨客户端边界无法可靠按组件身份提取标题。Collapse 改为显式 `header`，避免范围说明、审计筛选标题为空。
- 目录旧规则对所有后代 `span` 加左边距，误伤 Ant Design Checkbox 的内部节点。规则限定为目录计数，恢复复选框与名称对齐。
- 保留通过组件封装的可排序表头，避免仅识别静态表头而丢失列名、排序入口；增加先失败再通过的组件回归测试。
- DDT 筛选浮层的高度测量改为实际 Collapse 标题节点，修复 1024px 桌面筛选字段超出工作区。
- Ant Design Table 默认内联 `table-layout: auto` 覆盖执行明细的固定列宽。共享适配层保留业务列布局，并增加回归断言。
- 移除旧弹窗重复的全局 Escape 监听，避免同时关闭多层弹窗；终端保留先退出最大化、再关闭的行为。
- 子页 Tabs 为实际 `tablist` 补充可访问名称；主用例类型标签恢复图标与文字同行，导航链接继承所处标签状态颜色。
- 项目下拉的 Enter 选择阻止事件继续冒泡，避免恢复焦点后再次打开下拉。
- 执行详情、JAR 导入、开始分析列表及 DDT 导入／模板页的说明文字样式限定到说明节点，避免改变 Ant Design 按钮内部文字的颜色与字号；执行详情补充实际文字节点的对比度检查。
- 浏览器测试改用新的折叠节点、展开状态和组件语义定位，继续验证目录延迟加载、快照刷新后的展开状态、文件选择和表单提交。
- 离线资源校验覆盖 19 类组件 CSS，并逐个校验懒加载脚本、样式与其他静态资源的 SHA-256；缺失、内容不一致或 CSS 引用外部 URL 会阻止打包。

### 离线验收

最终产物经 `package-backend-runtime.mjs` 打包，用生产 Dockerfile 的运行层构建本机 `linux/amd64` 镜像，并经过 `docker save`、`docker load` 与 `verify-backend-image.sh`。tar 为 **130,605,568 字节**，容器校验通过 **218 个路由模块、81 个前端资源**。

浏览器通过 `nsenter --net` 进入 `docker --network none` 容器，只访问 loopback：完成管理员初始化，加载工作概览、DDT、用户管理、平台配置与审计，并打开中文日期选择器、执行弹窗。1024px 与 1536px 下均无页面横向溢出、外部请求、脚本错误或资源加载失败。结果见[断网浏览器记录](./ant-design-ui-audit/offline-browser.json)。

Full 专属节点配置使用真实前端组件和模拟接口完成双视口检查，验证地址保存、连通检查反馈、展开详情；错误页面使用真实组件验证重试回调。此项不等同于真实 Full 基础设施验收。本轮没有运行 Full 数据库／消息队列矩阵和 ARM64 构建；未修改相应后端语义。Docker 验证复用了本机构建依赖与生产运行层，没有重跑依赖下载阶段，也没有发布正式版本。

## 发布前 CI 补充检查

跨环境 CI 暴露了首轮本地复验未出现的时序及多条通知布局问题：日期选择器在首屏使用主题控件最小高度，导入用例入口在客户端事件绑定完成前保持禁用；多行通知改为内容自适应高度，已读与未读使用相同的独立内容布局，避免文本跨行覆盖相邻点击区域。新增多条长通知的双视口浏览器回归，保留内容边界检查与实际点击标记已读；SSR 回归检查导入按钮初始禁用。

Runner 安装测试区分可见 Ant Design 选择器与隐藏表单字段；用户角色测试直接验证提交字段的完整项目候选值。Go 进程树超时测试将夹具启动与被测超时分离，慢启动夹具先复现失败，修复后连续 30 轮验证子进程清理。浏览器普通控件操作上限为 30 秒，让持续遮挡及时留下 trace，不使用整轮自动重试隐藏失败。
