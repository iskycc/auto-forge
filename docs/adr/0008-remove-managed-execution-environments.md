# ADR 0008：退役受管执行环境与执行密文

状态：已接受（2026-08-21）；第 2、3 条中的参数决定由 ADR 0009 取代

## 背景

产品曾提供项目级受管环境变量、执行密文版本和 attempt lease 按需领取。该能力没有形成经过验收的用户闭环，却把任务编辑、预检、Runner Protocol、权限和失败恢复同时变成两套输入来源。任务还不能完整保存 Runner、项目版本和 Adapter 地址，用户每次执行都要重新组装配置。

## 决策

1. 删除受管执行环境与执行密文的导航、页面、管理 API、应用服务和新建任务输入。
2. `CaseSuite` 成为批量执行配置的唯一来源，保存 Runner/Runner Group、项目版本、参数、重跑、Adapter 地址和恢复时限；顶栏、计划任务和 Jenkins 只提交 `suiteId`。
3. 单用例快捷执行可提交一次性参数和 Adapter 地址，但不支持任意环境变量或平台密文。
4. Runner Protocol v1 与数据库历史列暂时保留空值兼容，保证旧库可迁移、旧记录可读取；新批次固定写入空快照，密文领取端点不再提供。
5. LDAP bind 密码、Runner/API 身份、SSH 安装档案和基础设施凭据不属于本次退役范围，继续按各自安全边界加密和审计。

## 影响

- 旧的执行环境/密文管理 API 是明确的破坏性移除；升级前应确认没有依赖这些端点的外部调用方。
- 历史批次仍可查看，但依赖已退役密文领取的未完成旧批次不能继续领取秘密，应在升级维护窗口终止并重新按任务配置执行。
- Lite 与 Full 使用同一任务和空兼容快照语义；不得只在一个数据库适配器中重新引入该能力。
- 如未来确有任意环境变量或秘密注入需求，必须提交新 ADR，重新评估日志/产物泄漏、权限、离线密钥生命周期、协议版本与真实 Agent E2E。
