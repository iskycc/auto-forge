## 页面与权限审计

- 所有登录用户可从顶栏进入账号安全页；强制改密账号只保留该闭环，LDAP 账号显示只读密码说明。
- 主导航和设置页标签按实际权限生成且一级/二级入口均固定为四个汉字；产品级执行环境与执行密文入口已经退役。
- 顶栏提供服务端校验的全局项目切换；首页、用例、JAR 导入、来源、任务、记录、洞察、审计和项目设置共享该上下文，页面不再重复提供项目切换。
- 用户、系统/项目角色、项目成员、负责人转移、服务账号生命周期、单次执行取消、审计筛选/导出、计划/LDAP 作业及用例版本差异均已有页面入口。
- 顶栏任务执行直接继承任务保存的 Runner/Runner Group、项目版本、重跑与 Adapter 地址；手工参数覆盖已移除，导入发现参数只读固化。API Key 可供 Jenkins 插件启动任务、替换版本依赖并读取免登录批次进展。
- 项目执行配置使用版本/测试阶段树；JDK 与依赖包按版本隔离，支持同项目版本间引用继承和安全删除。用例可按来源/目标测试阶段跨版本有界继承。
- 用例任务、快捷执行、执行记录、洞察、Runner 活动和计划视图统一跟随顶栏项目版本；任务成员与执行预检在服务端强制校验同版本，计划、Jenkins 与 API 无法绕过。
- 顶栏任务/单用例执行支持服务端持久化倒计时；计划开始前队列、调度器和 Runner 均无法提前领取，执行历史按“曾通过优先、否则最后轮次”展示最终用例统计。
- Jenkins 两个 HPI 均通过真实 Pipeline DSL 测试与打包结构校验，完整 Declarative Pipeline 示例位于 `examples/jenkins/Jenkinsfile`。
- 执行记录以权威批次生命周期展示：TestNG 断言/配置失败仍是“执行完成”，调度、Runner、进程、超时与上传链路未完整结束才是“执行异常”。计划任务总览支持永久删除。
