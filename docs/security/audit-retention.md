# 审计保留与完整性策略

AutoForge 的 `audit_events` 是权威安全记录。默认保留 730 天，支持配置 90–3,650 天，后台保留周期按配置有界清理。备份必须与业务数据库使用同一恢复点，并包含主密钥恢复材料的独立受控副本。

页面手动清理需要系统管理权限并确认类别，完成后写入中文审计，记录类别与删除数量。建议在缩短保留期或手动清理前，由具有审计导出权限的管理员按 UTC 时间范围归档，计算 SHA-256 并保存到受控介质；当前产品不自动生成归档摘要或校验归档是否完成。

当前数据库权限、备份和导出摘要提供完整性边界；尚未宣称具备 WORM 或外部时间戳证明。需要更强防篡改保证时，应通过 ADR 引入哈希链或离线签名归档，并定义密钥托管和验证工具，不能只依赖应用进程内秘密。

## 记录范围与查看

安全审计覆盖重要数据的增删改和身份访问安全：用例/来源、用例任务及计划、项目版本与运行资源、用户/角色/服务账号/令牌、平台配置与保留策略、执行机与执行机组。保留成功和失败的登录、退出登录、已认证请求的权限拒绝，以及共享授权和执行机终端访问。终端仅记录会话与有界流量摘要，不保存命令或输出。

执行发起、取消、自动/手工重试、执行进度、分析流程、普通查询、预览与连通性测试不进入安全审计。执行状态与重试信息仍在执行记录中保存。升级不会删除历史数据库记录；安全审计列表与 CSV 在数据库分页前按统一事件目录排除历史运行事件。

事件目录位于 `packages/contracts/src/security-audit.ts`，新增需要审计的操作必须同时登记中文名称。机器动作标识保持英文，作为稳定的 API 查询字段；新写入的 `details.eventDescription` 保存中文描述。页面、展开详情和导出使用中文操作、权限、结果和字段名称，历史事件也可按中文操作名搜索。

页面按每页最多 30 条展示，支持 URL 中的搜索、分类、操作、结果、操作者和时间条件。详情提供对象与请求编号；时间按平台配置时区展示，时间提示保留 UTC 原值，CSV 时间列明确为 UTC。导出沿用相同筛选和权限，每次最多 5,000 条。系统审计管理员在选中项目下同时查看该项目和全平台事件，项目审计员只能查看授权项目内事件。
