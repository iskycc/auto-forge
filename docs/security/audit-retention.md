# 审计保留与完整性策略

AutoForge 的 `audit_events` 是权威安全记录。默认不自动删除；备份必须与业务数据库使用同一恢复点，并包含主密钥恢复材料的独立受控副本。生产环境应根据组织合规要求配置保留期，建议不少于 180 天。

清理流程必须由具有 `audit.export` 和系统管理权限的管理员发起：先按 UTC 时间范围导出，计算归档文件 SHA-256，将归档和摘要写入只读介质，再在维护窗口执行有界批量删除。清理动作本身在删除范围之外写入新的审计事件，记录范围、条目数和归档摘要。

当前数据库权限、备份和导出摘要提供完整性边界；尚未宣称具备 WORM 或外部时间戳证明。需要更强防篡改保证时，应通过 ADR 引入哈希链或离线签名归档，并定义密钥托管和验证工具，不能只依赖应用进程内秘密。
