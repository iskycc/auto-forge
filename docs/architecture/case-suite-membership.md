# 任务用例变更记录与标识

Lite 与 Full 在成员增删事务中记录实际变化、操作人账号快照、备注和用例标识信息。任务详情分页查询记录和当次变更涉及的用例。任务归档保留这些记录，删除任务会清理任务内记录和标识。

标识按成员保存，支持五个独立的文本位置。更新时校验任务版本与成员归属。任务批次创建时，标识随执行规格保存到批次关联的执行记录，供失败分析导出。之后修改标识或删除任务，已执行批次仍可按原有快照导出。

## 升级与恢复

Lite 的迁移为 `0103_case_suite_membership.sql`，Full 为 `0102_case_suite_membership.sql`。两份迁移仅新增表和索引，已有批次、任务及其成员可继续读取。升级前备份平台数据库，并使用当前发布物的正常迁移流程。已有任务从升级后开始记录成员变更。标识快照从升级后新建的批次开始保存。迁移在事务内执行，运行失败时可修复报错后重跑。需要整体回退时，停写并恢复升级前备份，再启动对应版本。
