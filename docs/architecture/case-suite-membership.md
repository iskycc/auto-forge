# 任务用例变更记录与标识

Lite 与 Full 在成员增删和标识变更事务中记录实际变化、操作人账号快照和原因。任务详情分页查询记录和当次变更涉及的用例。任务归档保留这些记录，删除任务会清理任务内记录和标识。

标识按成员保存，支持五个独立的文本位置。更新时校验任务版本与成员归属。导出失败结果或失败分析清单时，按批次关联的任务、执行记录的用例类型和用例 ID 分页匹配当前标识。已结束的批次也读取这份数据。清空标识、移除成员或删除任务后，对应历史执行行仍可导出，标识留空。

任务详情分区栏中的“用例标识”打开按需加载的浮窗。成员类型、搜索、分页、编辑和 XLSX 导入导出均由浮窗提供，读取和编辑继续使用任务权限与同一修订号。

任务锁定时，拥有任务管理权限的用户仍可编辑或导入标识。任务归档期间的标识编辑和成员增删均需先恢复任务。新增用例、移除用例和标识编辑请求的 JSON 包含必填 `remark`，标识导入通过 multipart 表单字段 `remark` 提交原因。仅包含空白字符的原因无法提交，最多 500 字。

标识表导出“用例”和“标识1”至“标识5”。导入按普通用例完整类路径或 DDT CaseID 精确匹配当前任务成员。旧表格可保留前置的“用例类型”“成员 ID”列。遇到未匹配或重复的用例，整批拒绝并报告行号。导入时分页匹配成员，写事务再次验证任务修订号及成员归属。

## 升级与恢复

Lite 的 `0104_case_suite_marker_history.sql` 和 Full 的 `0103_case_suite_marker_history.sql` 扩展用例变更记录的操作类型，保留已有记录、操作人和原始原因，包括旧版本允许的空备注。历史批次仍从任务成员读取当前标识。升级前备份平台数据库，迁移在事务内执行，运行失败时可修复报错后重跑。需要整体回退时，停写并恢复升级前备份，再启动对应版本。
