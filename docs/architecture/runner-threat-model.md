# Runner 执行威胁模型

状态：已完成首版威胁建模；每次新增执行器、终端能力或上传类型时必须更新。

## 资产与信任边界

需要保护的资产包括平台用户会话、Runner/API 身份、用例输入、宿主机文件、日志/产物完整性和执行结果。边界如下：

- 浏览器与控制面之间是不可信网络；所有授权在服务端重新判断。
- 控制面信任经过认证的 Runner 身份，但不信任其上报内容、时间和资源数字。
- Runner 信任显式配置的控制面地址和 CA，但必须校验每个 `ExecutionSpec` 与本地策略。
- 上传的 JAR、测试命令、stdout/stderr、报告和产物内容均视为不可信。
- `process` 执行器与宿主机共享内核和 Agent 服务账号权限，不是强隔离沙箱。
- 直连终端等同于操作者获得 Agent 服务账号的交互能力，是独立高风险权限。

## 主要威胁与控制

| 威胁                   | 必需控制                                                          | 剩余风险                                |
| ---------------------- | ----------------------------------------------------------------- | --------------------------------------- |
| 恶意 JAR 在导入时执行  | 只做有界 ZIP/class 静态解析，不使用 class loader                  | 解析器缺陷仍需模糊测试和大小限制        |
| 命令/Shell 注入        | `executable + args[]`、`shell: false`、可执行文件白名单、参数上限 | 被允许程序自身可能解释危险参数          |
| 路径穿越和符号链接逃逸 | 新 attempt 目录、规范化相对路径、拒绝绝对路径/`..`/越界链接       | TOCTOU 需要安全打开方式和最小权限       |
| 子进程逃逸或遗留       | 专用低权限用户、进程组、超时/取消后两阶段清理、cgroup/ulimit      | process 模式仍能访问服务账号可见资源    |
| 资源耗尽               | CPU、内存、磁盘、进程、日志、产物、时间和并发上限                 | 内核/容器能力不足时必须拒绝或告警       |
| 凭据或主机信息泄漏     | 用例不继承 Agent 环境、日志双层脱敏、spool 不存控制面凭据         | 用例仍可能读取测试数据，需网络隔离      |
| 重放或伪造结果         | TLS、Runner 凭据、lease token/版本、幂等 completion ID、摘要      | 已攻陷 Runner 可在权限范围内伪造执行    |
| 日志/ANSI 注入         | 有界 UTF-8 文本、ANSI 白名单解析、禁止 HTML 注入                  | 欺骗性文本仍需明确 stream 和来源        |
| 恶意产物               | 路径/类型/大小/数量/SHA-256 校验、安全下载头                      | 允许预览的复杂格式仍可能攻击浏览器      |
| 终端越权               | 默认关闭、独立 RBAC、短时一次性票据、同源检查、时限/并发、审计    | 获权管理员可以执行服务账号允许的命令    |
| 网络分区导致双执行     | 独立 lease、条件续租、reconcile、迟到结果隔离                     | grace window 内可能短暂并行，需明确策略 |
| Agent 凭据被盗         | `0600` 落盘、可撤销/轮换、请求限速、异常审计                      | 宿主机 root 可读取凭据，需主机安全      |

## 部署要求

- Agent 默认以专用非 root 用户运行，数据目录仅该用户可读写；显式 root 模式会扩大测试与直连终端的宿主机访问范围，只适合专用受控节点。
- 生产执行不可信用例时使用专用主机或经过评审的容器/虚拟机隔离，并默认阻断不需要的出站网络。
- Runner 本地策略只能收紧控制面命令、路径、资源和工具链范围，不能被 assignment 放宽。
- 控制面和 Agent 限制请求体、并发、重试、日志/产物总量；任何截断或拒绝都形成可见结果。
- 私有 CA、Runner 凭据和主密钥使用不同生命周期和访问权限。

## 验证清单

- Shell 注入、恶意参数、越界 cwd、绝对/父级路径和符号链接测试。
- 超时、取消、lease 拒绝、Agent 关闭后的完整进程树清理测试。
- 日志跨块秘密、ANSI/HTML 注入、磁盘满、重复/缺口/重传测试。
- 产物超限、设备文件、摘要冲突、重复上传和危险 Content-Type 测试。
- 失效/撤销凭据、协议降级、重放、跨 Runner assignment 和终端越权测试。
- 同一 Agent 在 Lite/Full 以及断网环境完成兼容和恢复验收。
