# 站内使用文档

## 使用入口

`/docs` 是面向平台使用者的文档首页，`/docs/<topic>#<section>` 是稳定的功能章节地址。
工作台顶栏提供“使用文档”图标；公开首页、任务执行、批次详情、用例日志、用例分析、历史进展与用例分享页提供入口。功能说明在新标签页打开，链接不携带原页面的分享凭据、参数或用户信息。

文档本身允许匿名阅读，实际用例、执行、日志及分析接口继续遵循原权限和公开授权。代理只放行 `/docs` 与 `/docs/` 下的页面，不放行相似前缀或后台 API。不存在文档上传、在线编辑或任意 HTML 执行入口。

## 内容与示意图

- `apps/web/src/lib/user-documentation/model.ts` 定义主题、章节、搜索和地址契约。
- 同目录下按上手、用例、执行协作、平台管理维护文章，`catalog.ts` 汇总目录。
- `apps/web/src/components/user-documentation/` 使用共享主题的 Ant Design 组件展示导航、搜索、步骤、表格和提示。
- 每篇文章使用可访问的 SVG 流程示意图；文字、颜色与箭头在本地渲染，随全局深浅主题切换，不依赖 CDN、字体服务、在线绘图服务或新增依赖。

顶栏与公开页面只导入轻量入口和地址契约，不加载全部文章。文档路由只传递当前文章和目录摘要；导航不预取所有文章。搜索在浏览器按目录摘要执行，条件保留在 URL，可刷新及通过浏览器历史恢复，不为每次按键请求后台。文档没有轮询、后台任务、数据库迁移或中间件依赖，Lite 和 Full 使用相同实现。

章节锚点在文章完成浏览器渲染后再次定位，避免流式首屏尚未包含目标章节时丢失跳转位置；刷新深层章节地址也保留定位。

“本页内容”使用可换行的 Ant Design 章节链接，仅在点击或键盘确认时跳转，保留原生片段地址、浏览器前后退和章节顶部留白。阅读滚动不更新目录高亮，也不触发目录链接的自动滚入可视区，避免横向 Anchor 在目录离开屏幕后将正文拉回、造成页尾抽动。长文底部及目录跳转由 Playwright 逐帧检查，Lite／Full 共用这条前端路径。

## 更新要求

用户可见功能变更必须在同一变更中更新对应文章、示意图、步骤、权限及常见问题。新增公开功能时接入 `DocumentationLink`，传入已有主题与章节。已有路径及章节锚点是外部链接契约，不随标题调整而删除；必要时保留兼容章节。CHANGELOG 和架构文档不能代替使用说明。

目录、主题与公开直达章节由 `catalog.test.ts` 校验；页面访问边界由 `proxy.test.ts` 校验；Playwright 验证匿名阅读、搜索、主题、文档跳转与带数据的公开页面入口。修改 UI 必须生成并实际查看至少 1024px 和一个大屏视口的截图，覆盖深浅主题、长文、空搜索结果与原页面布局。

本功能不改变执行调度、Runner 协议、存储或授权；阅读文档也不产生业务写入。
