## 回归中实际发现并修复的问题

- SQLite API Token 认证在读取后写入 `last_used_at` 时，后台快照写入可导致读锁升级失败。新增两个真实连接的确定性复现测试，写事务在入口取得保留写锁。
- PostgreSQL 来源清理缺少用例反向引用索引；十万级级联删除会长时间占用数据库。新增双数据库索引并验证事务升级与回滚。
- PostgreSQL 新批次的重试计数可能选择重复求值的查询计划。明确物化重试集合；保留无重试和重试结果的既有语义，并重新运行十万级批次创建、调度测试。
- 冷终态统计不能展示为零，且需要继续轮询至生成完成；公开进度同样适用。执行历史的占位符保持在原有列宽内。
- 分析任务认领后刷新页面，统计必须保留刚完成的认领；重新读取当批次权威认领数。
- 单用例取消审计补充项目归属，使相应统计失效并由后台更新。
- Full 存储分页不能在多个节点的本地目录之间切换；转发重新鉴权，拒绝循环、错误节点身份及不可达节点。
- 存储分页尚未完成时不能提前开放批量删除；延迟后续分页的浏览器测试验证加载状态，既有测试继续要求删除不重新读取清单且保留树展开与滚动位置。

## 十万级验证

固定测试包含 100,000 个用例、100,000 个任务成员、100,000 条执行记录及对应 attempt。SQLite 和真实 PostgreSQL 使用同一测试流程。验证 400 个目录分块、权限隔离、冷读不计算、重复读不重新构建、结果通过数、分页键及记录一致性，以及终态版本变更后旧统计不会冒充新结果。

本机一次包含其他回归负载的实测结果：

| 项目                                                              |   SQLite | PostgreSQL |
| ----------------------------------------------------------------- | -------: | ---------: |
| 100,000 用例目录后台生成                                          | 3,592 ms |  36,333 ms |
| 100,000 任务成员后台生成                                          | 3,758 ms |  15,271 ms |
| 100,000 执行记录中，按名称排序的总结页键生成                      |   625 ms |     789 ms |
| 连续 100 次读取已生成的执行概要、任务目录、历史计数和页键，总用时 |   366 ms |   2,326 ms |

这些时间反映该测试机器与当时负载，不是生产 SLA。首次构建仍需实际计算，超出浏览器 24 MiB 缓存预算的目录也可能重新下载。目标是页面请求不承担全量聚合、重复访问复用结果，且准备期间保留可用操作。

## 可复现的检查

- `pnpm test`：普通 TypeScript / Go 测试及发布、运维脚本测试。
- `AUTOFORGE_TEST_POSTGRES_URL=... pnpm exec vitest run integration.test --no-file-parallelism`：两个数据库的迁移、仓储、执行状态机与并发路径。使用独立测试数据库；失败中断留下的固定 fixture 不可复用作干净验收库。
- `AUTOFORGE_TEST_POSTGRES_URL=... pnpm exec vitest run --config vitest.performance.config.ts tests/performance/read-model-load.test.ts`：上表的共享压力测试。
- `pnpm test:e2e`：既有执行、导入、分析、权限、配置、日志分享和桌面布局回归；`read-model-cache.spec.ts` 额外检查分块请求数量、浏览器复用、导入后失效、权限拒绝、任务配置可用性和 1024 / 1536 像素截图。
- `pnpm format:check`、`pnpm lint`、`pnpm typecheck`、`pnpm build`：交付质量检查。

未启动 NATS、MinIO 等服务时，对应集成测试会按原有配置跳过；不能将这种运行称为完整 Full 基础设施或离线验收。当前改动未变更 Runner 协议、队列、对象存储协议或发布方式。

日常 CI 和发布检查中的 Full `contracts` 阶段已加入快照、分析任务迁移、用户分配契约及十万级读模型测试；Lite 继续通过统一集成及性能测试入口执行。浏览器缓存场景进入 Lite 浏览器矩阵。
