# 身份、权限与数据作用域

状态：本地/LDAP 统一身份、安全会话、六种内置角色、项目角色绑定、服务端授权、审计查询和执行数据项目过滤已实现 Lite/Full 适配器。所有业务聚合的租户键、项目成员完整生命周期和 API 服务账号仍属于后续多租户工作。

## 授权模型

认证会话每次从权威数据库解析，不把权限快照只保存在 Cookie 或 Redis。身份同时携带系统权限和按项目分组的项目权限：系统权限可访问所有项目；项目权限只能用于绑定项目。没有明确授权时默认拒绝。

当前六种内置角色的关键入口矩阵如下：

| 角色           | 执行页面 | 创建/取消 API | 日志/产物 | 直连终端 | 身份/LDAP 管理 |
| -------------- | -------- | ------------- | --------- | -------- | -------------- |
| 系统管理员     | 允许     | 允许          | 允许      | 允许     | 允许           |
| 项目管理员     | 允许     | 允许          | 允许      | 允许     | 拒绝           |
| 测试管理员     | 允许     | 允许          | 允许      | 拒绝     | 拒绝           |
| 执行操作员     | 允许     | 允许          | 允许      | 拒绝     | 拒绝           |
| 只读观察者     | 允许     | 拒绝          | 允许      | 拒绝     | 拒绝           |
| 审计员（系统） | 允许     | 拒绝          | 允许      | 拒绝     | 拒绝           |

直连终端在当前全局 Runner 模型下绑定默认项目权限；Runner 加入明确项目前，不把任意项目的终端权限扩展到全局节点。

## 数据作用域

批次创建固化 `projectId`。批次列表在仓储查询中加入允许项目集合，详情对不允许项目返回不存在。日志、Attempt 时间线和产物元数据在读取前通过 `RunAttempt -> ExecutionRun -> RunBatch` 解析权威项目；项目不匹配时不执行内容查询，也不读取对象存储。取消 run 同样先验证所属项目。Runner 使用独立身份和有效 lease 的写路径不接受用户项目 scope 参数。

用例、来源和任务当前属于默认项目，所以对应页面与 API 明确校验默认项目权限。将这些聚合、Runner、对象键和缓存键扩展为完整多租户模型属于 AF-IAM-016，不能把当前执行数据过滤描述为已经完成全量租户隔离。

## 会话与 LDAP 故障

- 用户禁用、密码重置、角色增删和管理员撤销都会使既有会话失效；过期时间使用服务端 UTC 判断。
- LDAP 目录失联时，已建立且未过期的本地会话继续按数据库权限工作，本地系统管理员不依赖目录。
- 新 LDAP 登录保留 DNS、TLS、连接超时等可操作错误码；错误凭据仍返回通用认证失败，避免账号枚举。
- 同步发现用户或组资格消失时禁用目录用户并撤销会话，历史执行只保留稳定用户 ID 归属。

Lite SQLite 集成夹具覆盖组映射、停用、会话撤销、目录失联和权限实时变化；共享领域矩阵覆盖六角色页面/API/产物/终端结果。PostgreSQL 集成套件运行同一批次项目过滤行为。

## 持久审计边界

登录与登出、LDAP 配置/测试/同步、用户/角色/项目变更、用例来源和任务变更、批次创建与取消、执行取消、Runner 注册与管理、终端会话生命周期都写入权威数据库的 `audit_events`。自动重试由系统身份记录 `execution_run.retry_scheduled`，并与 attempt 终态、run 重排和批次聚合在同一个数据库事务中提交；幂等完成上报不会重复产生审计记录。

审计详情只保存稳定 ID、结果码、attempt 序号等脱敏摘要，不保存密码、LDAP bind 密码、Runner/lease/API 凭据、命令或终端输出。产品级执行环境与执行密文已经退役，不再产生按 lease 领取密文的审计事件。
