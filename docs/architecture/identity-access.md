# 身份、权限与数据作用域

状态：本地/LDAP 统一身份、安全会话、六种内置角色、项目角色绑定、服务端授权、审计查询和执行数据项目过滤已实现 Lite/Full 适配器。用例、来源、任务、项目成员和 API 服务账号已支持项目授权；Runner 仍为共享基础设施，不能把这描述为完整的多租户隔离。

## 授权模型

认证会话每次从权威数据库解析，不把权限快照只保存在 Cookie 或 Redis。身份同时携带系统权限和按项目分组的项目权限：系统权限可访问所有项目；项目权限只能用于绑定项目。没有明确授权时默认拒绝。

当前六种内置角色的关键入口矩阵如下：

| 角色           | 执行页面 | 创建/取消 API | 日志/产物 | 直连终端           | 身份/LDAP 管理 |
| -------------- | -------- | ------------- | --------- | ------------------ | -------------- |
| 系统管理员     | 允许     | 允许          | 允许      | 允许               | 允许           |
| 项目管理员     | 允许     | 允许          | 允许      | 默认项目授权时允许 | 拒绝           |
| 测试管理员     | 允许     | 允许          | 允许      | 拒绝               | 拒绝           |
| 执行操作员     | 允许     | 允许          | 允许      | 拒绝               | 拒绝           |
| 只读观察者     | 允许     | 拒绝          | 允许      | 拒绝               | 拒绝           |
| 审计员（系统） | 允许     | 拒绝          | 允许      | 拒绝               | 拒绝           |

执行页面的控件按当前选择项目计算，不合并其他项目的权限。直接打开其他项目资源时按资源所属项目鉴权；选中的项目无该页面权限时明确拒绝，不悄悄切换到另一个项目。

- 新执行、任务执行、Jenkins 和个人调试使用 `run.create`；停止使用 `run.cancel`；日志重跑与最终失败重跑使用 `run.retry`。重新执行已保存的完整任务仍是新执行。
- 执行机/机组读取接受任意已授权项目的 `runner.read`；执行对话框和调试工作台明确传当前执行项目，不再隐式校验默认项目。它们仍是共享目录，不代表节点属于该项目。
- 共享 Runner 管理与直连终端要求系统授权，或默认项目中显式授予相应权限。任意其他项目的管理员不会因此获得全局节点管理或终端权限。
- 用户、角色、LDAP、平台设置和服务账号管理只接受系统范围授权；项目角色中的同名权限不会提升成系统权限。
- 自定义角色创建后不能切换系统/项目范围；需创建新角色重新分配。停用用户、撤销绑定、停用角色或移除管理权限，都在数据库事务中保护最后一位恢复管理员。一个用户可通过多个系统角色组合拥有 `user.manage` 和 `role.manage`；SQLite 使用短写事务，PostgreSQL 使用事务级锁串行化这些管理变更，普通鉴权仍只读。

## 数据作用域

批次创建固化 `projectId`。批次列表在仓储查询中加入允许项目集合，详情对不允许项目返回不存在。日志、Attempt 时间线和产物元数据在读取前通过 `RunAttempt -> ExecutionRun -> RunBatch` 解析权威项目；项目不匹配时不执行内容查询，也不读取对象存储。取消 run 同样先验证所属项目。Runner 使用独立身份和有效 lease 的写路径不接受用户项目 scope 参数。

用例、来源、任务、DDT、调试与执行按实际项目校验；版本/阶段还需属于该项目。全局搜索分别按 `case.read`、`case_suite.read`、`run.read`、`runner.read` 查询对应资源，不能用一种资源的权限扩大另一种资源的范围。通知范围不因无关的系统用户管理权限扩大。

后台快照按查询实际涉及的项目校验，不能把缓存命名空间当成数据范围。分析导出的状态、取消和下载在每次请求中重新检查所有原始项目，撤销权限后不能借助旧文件继续访问数据。

公开 DDT 只读 API、签名分享页、健康检查和登录引导属于显式公开入口；Runner、节点互访和 WebSocket 使用独立凭据/签名票据。API Token 权限为账号授权与令牌 scope 的交集；显式提供无效 Authorization 时拒绝，不回退到浏览器 Cookie。服务账号不能进入个人调试/变更审核，也不能创建浏览器终端会话。

## 会话与 LDAP 故障

- 用户禁用、密码重置、角色增删和管理员撤销都会使既有会话失效；过期时间使用服务端 UTC 判断。
- LDAP 目录失联时，已建立且未过期的本地会话继续按数据库权限工作，本地系统管理员不依赖目录。
- 新 LDAP 登录保留 DNS、TLS、连接超时等可操作错误码；错误凭据仍返回通用认证失败，避免账号枚举。
- LDAPS 默认校验证书链和主机名；管理员可显式关闭服务器证书校验以兼容隔离的旧目录，并在 UI
  和 `ldap.configure` 审计详情中保留风险状态。
- LDAP Group 只保存为用户资料，不参与角色或权限计算；平台不遍历目录执行账号同步或离职停用。

Lite SQLite 集成夹具覆盖 LDAP 即时建号、Group 资料、停用、会话撤销和目录失联；共享领域矩阵覆盖六角色页面/API/产物/终端结果。PostgreSQL 集成套件运行同一批次项目过滤行为。

## 持久审计边界

登录与登出、LDAP 配置/测试、用户/角色/项目变更、用例来源和任务变更、批次创建与取消、执行取消、Runner 注册与管理、终端会话生命周期都写入权威数据库的 `audit_events`。自动重试由系统身份记录 `execution_run.retry_scheduled`，并与 attempt 终态、run 重排和批次聚合在同一个数据库事务中提交；幂等完成上报不会重复产生审计记录。

审计详情只保存稳定 ID、结果码、attempt 序号等脱敏摘要，不保存密码、LDAP bind 密码、Runner/lease/API 凭据、命令或终端输出。产品级执行环境与执行密文已经退役，不再产生按 lease 领取密文的审计事件。

## 授权回归入口

- `tests/e2e/identity-rbac.spec.ts` 从 Route Handler 源文件枚举 HTTP 方法，对受保护入口逐一验证匿名拒绝，并记录请求结果；明确公开入口单独列出，Runner/节点互访验证独立凭据拒绝。动态 DDT 子路径的业务权限继续由 DDT、调试和变更审核 E2E 覆盖。
- 同一套 E2E 以非默认项目的执行操作者完成资源读取、预检、创建和取消任务，再切到只读项目验证执行入口隐藏及直接 API 拒绝；原有六角色、用户管理、服务账号、项目隔离和安全审计回归保留。
- `authorization-paths.test.ts` 覆盖共享 Runner、显式系统权限、令牌优先级、个人终端和重跑权限；`read-model-authorization.test.ts` 覆盖快照源项目边界。
